# Labels and Masks

How per-leaf **labels** and **masks** travel from a dictionary entry, through a
generator, into the editor, and back to disk. The surface spans four packages; this is
the single map.

---

## 1. What lives where

| Layer | Shape | Home |
|---|---|---|
| **On disk** | `M0cFile` — `m0` + `labels` (`Record<StableKey, M0Label>`) + `masks` (`Record<StableKey, M0cMaskEntry \| null>`) + `fill` + `size` | https://github.com/m0saic-dsl/m0/blob/main/packages/dsl-file-formats/src/types.ts |
| **Dictionary entry** | `MosaicDictionaryEntry.labels` / `.masks` — same maps at runtime | https://github.com/m0saic-project/m0saic-packages/blob/main/packages/types/src/dictionary/dictionary.ts |
| **Editor (live)** | `m0cExtrasRef` — `{ labels, masks, derive, custom }` for the open canvas | the Mosaic Desktop / Web app source (not published) |
| **Generator output** | `GeneratorResult.m0c?: string` — optional serialized blob | https://github.com/m0saic-project/m0saic-packages/blob/main/packages/dictionary/src/generators |

> **`labels[k].color` ≠ the rect fill.** `labels[k].color` tints the *badge*; `fill[k]`
> paints the *rect*. The inspector once conflated them — don't re-conflate.

## 2. Dictionary entry convention

- An entry MAY ship **`m0saic.m0c`** instead of `m0saic.m0`. The `.m0c` is
  authoritative; `loadEntryM0()` auto-detects by filename and **throws if both exist**.
- **`m0saic_src.m0`** is a read-only sibling auto-regenerated by `validate.js`, carrying
  a `# note:` header. It exists for grep-by-DSL and human inspection. **No runtime reads
  it** — never edit it, never treat it as a source.
- **`entry.masks`** (StableKey-keyed) is the canonical mask path. `entry.maskSets` /
  `getMaskSet()` is reserved for future *named alternate* sets — no current entry uses
  it. Don't reach for it.
- Positional lookup goes through `getSourceOrderStableKeys(entry)`
  (https://github.com/m0saic-project/m0saic-packages/blob/main/packages/dictionary/src/sourceOrder.ts#L50, memoized per `(entry.id, m0.length)`).
  See logo v2/v3 and qr-animate.
  ⚠️ **It throws when `entry.m0` isn't inlined.** Heavy entries carry a lazy
  `entry.m0File` instead. For those, call `resolveM0saic(entry)` first and pass the
  resolved string to the companion **`getSourceOrderStableKeysForM0(id, m0, w, h)`**.
  The error message says this, but only after you've already hit it.
- One-shot migrations live in **https://github.com/m0saic-project/m0saic-packages/blob/main/packages/dictionary/tools** (not repo-root `tools/`):
  `migrate-masks-to-m0c.mjs` converts legacy `masks.json` + `.m0` → `.m0c`;
  `normalize-mask-paths.mjs` runs the drop-rect-shaped + snap-to-bounds cleanup. Both
  route through `parseM0StringComplete` to turn positional masks into per-StableKey
  entries.

## 3. Generator label tiers

Every label-emitting generator exposes `labels: LabelTier`
(`"silent" | "signposts" | "atlas"`) built via `labelTierParam({ defaultTier })`
(https://github.com/m0saic-project/m0saic-packages/blob/main/packages/dictionary/src/generators/labelTier.ts).

| Tier | Emits |
|---|---|
| `silent` | plain m0, no labels |
| `signposts` | named structural regions only ("hero", "feature") |
| `atlas` | signposts + per-cell / per-level enumeration |

`off` is accepted as a spelling alias for `silent`; **`silent` is the canonical wire
value**. Resolve untrusted input with `resolveLabelTier(raw, fallback)`.

### Per-generator defaults and emission path

Two emission paths, and which one a generator uses is not arbitrary:

- **`emitLabeledM0c({ m0, size, app, tier, labelsBySourceIndex, keyedLabels })`** —
  use when labels map **positionally** to logical source order. Handles
  source-index → stableKey translation, including a feasibility-fallback probe
  scale-up for high-precision layouts.
- **Direct `serializeM0cFile`** — use when the generator must **classify nulls by
  position** or carries masks. Parse the m0, compute the placed-content bbox, classify
  each `kind: "null"` editorFrame by centroid offset into `padding-top` /
  `padding-right` / `padding-bottom` / `padding-left`. The same algorithm appears in
  every padding-classifying generator — copy it, don't re-derive it.

| Generator | Default tier | Path |
|---|---|---|
| `qrCodeGenerator` | **`signposts`** | direct |
| `barcodeGenerator` | **`signposts`** | direct |
| `aspectFit` | `silent` | direct (padding classification) |
| `placeRect` | `silent` | direct (padding classification) |
| `snapGrid` | `silent` | direct (padding classification) |
| `aspectSafeGrid` | `silent` | direct (padding classification) |
| `grid` | `silent` | `emitLabeledM0c` |
| `spotlightGenerator` | `silent` | `emitLabeledM0c` |
| `magazineGenerator` | `silent` | `emitLabeledM0c` |
| `comparisonGenerator` | `silent` | `emitLabeledM0c` |
| `rankedListGenerator` | `silent` | `emitLabeledM0c` |
| `goldenLayout` | `silent` | `emitLabeledM0c` |
| `goldenSpiralGenerator` | `silent` | `emitLabeledM0c` |
| `safeCanvas` | `silent` | `emitLabeledM0c` |

**`silent` is the default everywhere except the two code generators** (QR, barcode),
which default to `signposts` to preserve their always-on label channel.

*Keep this table in sync when adding a generator — verify with
`grep -A3 "labelTierParam(" https://github.com/m0saic-project/m0saic-packages/blob/main/packages/dictionary/src/generators/*.ts.*

## 4. Editor rendering and drop rules

**Chip render gate** — `Frame.tsx`: `canShowLabel = hasLabel && minPx >= 70`. There is
**no kind filter here**: frames, plain nulls, and passthroughs all wear chips once
mounted. Visibility moved upstream to the `showNullFrames` toggle, which controls
whether nulls reach `displayFrames` at all.

**Drop-label remap** — `ViewFrame.tsx` `buildDropZone`:

```ts
const isLabelable = (f) => f.kind === "frame" || f.kind === "null";
```

⚠️ **The root node is deliberately excluded.** Including it shifts every
position-slice mapping by one — the off-by-one that mislabeled aspectFit's `content`.
Bare-`F` drops (canvas was `"r"`) take a separate path: the new canvas *is* the dropped
m0, so labels apply with their original keys.

> **Name collision — two different `isLabelable`.** `ViewFrame`'s is **node-kind**
> based (above). `App.tsx`'s is **format** based
> (`loadedFormat === "m0c" || loadedFormat === "m0p"` — can this file carry labels at
> all). Same identifier, unrelated meanings, different files. Check which one you're
> reading.

**Why no `isLogicalOwner` requirement.** aspectFit-style generators label plain `-`
nulls (border padding). Requiring `-{...}` overlay anchors would force every
padding-labeling generator to wrap each null in an overlay purely to make it visible.
The relaxed rule lets any structural node carry a label, matching the `.m0c` format's
own permissiveness.

## 5. Undo participation

`useUndoRedoText(initial, { onCommit, onUndo, onRedo })` exposes side-channel
callbacks. `App.tsx` snapshots `{ labels, masks }` from `m0cExtrasRef` into a parallel
stack on every text commit, and restores on undo/redo.

- Manual `setFrameLabel` edits **between** commits don't push their own entry — they're
  absorbed into the *next* commit's snapshot. So manual label → text edit → Ctrl-Z
  restores the manual label too.
- Drop-derived labels vanish cleanly on Ctrl-Z because the snapshot at the drop's commit
  is taken **before** the handler merges drop labels (`setProfileText` calls `onCommit`
  synchronously, ahead of the `m0cExtrasRef` mutation). This ordering is load-bearing.

## 6. UI affordances

- **The dictionary panel's drag chip is the sole apply path.** Click-drag splices into a
  frame; double-click replaces the canvas (confirm modal when the canvas has structure;
  bare-`F` skips the prompt). The standalone "Use Layout" button was **removed** — it
  duplicated the pipeline and kept drifting.
- **Save-As gates `.m0`** whenever labels or masks exist (`m0SaveBlocked` in `App.tsx`).
  Both the Cmd/Ctrl+S guard and the format chooser respect it — a `.m0` save would
  silently drop the sidecar maps.

## 7. Settled items (don't re-debate)

- `aspectSafeGrid` carries m0c only on the **landscape primary** variant; portrait
  alternates don't support m0c yet. Noted in its labels-param description.
- `LabelTier` naming is **settled**. Renaming touches ~14 generators plus the panel UI.
- Outer-gutter nulls in `safeCanvas` are **not** labeled — canvas margin, not
  addressable cells.

predates this convention — read this doc for the entry convention and tier param.
