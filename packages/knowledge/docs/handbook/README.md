# handbook/ — canonical DSL truth

The authoritative layer (contract §0): grammar, semantics, and the geometry math.
On any conflict with skills/ or templates/, this folder wins; the code wins over
this folder.

## Read order

1. [`m0-construction-methods.md`](m0-construction-methods.md) — **the entry
   point**: every way to produce an m0, the four currencies, the canonical
   8-rung launder ladder, pairwise discriminators.
2. [`dsl-rules.md`](dsl-rules.md) — what's legal: surface grammar, tokens,
   canonicalization, the 11 error codes × kind taxonomy, warnings surface.
3. [`feasibility-precision-quantization.md`](feasibility-precision-quantization.md)
   — will ONE split render, look right, stay balanced: the two independent
   floors, the three drafting modes (§3c), quantization fixes. **Start here for
   any geometry work** (contract §1).
4. [`composition-arithmetic.md`](composition-arithmetic.md) — will STACKED
   splits work: prime-factor budgets, the 5-smooth invariant, base×fiber,
   hereditary quantization.
