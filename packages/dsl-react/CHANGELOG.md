# Changelog

## 0.2.0 — 2026-09-19

### First npm publish

`@m0saic/dsl-react` — The Layout → React bridge: render an m0 layout's labeled regions as absolutely-positioned React boxes. Depends on `@m0saic/dsl` and React (peer) only.

Published at the same source as the `m0saic` CLI 0.2.0 line (the CLI bundles its own copy). `0.x`: the surface is still being shaped; minor versions may change exports, and every change from here on carries a `pending-releases/dsl-react/` entry.
