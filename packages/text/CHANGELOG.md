# Changelog

## 0.2.0 — 2026-09-19

### First npm publish

`@m0saic/text` — Node-only text → SVG glyph-path engine over `opentype.js` with bundled deterministic fonts (Roboto, JetBrains Mono) so renders do not depend on host fonts.

Published at the same source as the `m0saic` CLI 0.2.0 line (the CLI bundles its own copy). `0.x`: the surface is still being shaped; minor versions may change exports, and every change from here on carries a `pending-releases/text/` entry.
